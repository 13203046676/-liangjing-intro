# 第一次作业：个人简介

## 作业内容

本作业是 HTML 基础实训作业，主题为热门影视剧《两京十五日》的简介网页。页面主要包含以下几个部分：

- **剧照**：展示官方海报和 3 张人物剧照（使用 `<img>` 标签，图片存放在 `./images/` 目录，通过相对路径引用）
- **剧情简介**：用三段文字介绍电视剧的基本信息和剧情梗概（使用 `<p>` 标签）
- **演员列表**：列出主要演员及其饰演角色（使用 `<ul>` 和 `<li>` 标签）
- **预告片**：嵌入本地预告片视频（使用 `<video>` 标签），并附上爱奇艺、B站的在线观看超链接（使用 `<a>` 标签）

## 使用到的 HTML 标签

| 标签 | 用途 |
|------|------|
| `<h1>` `<h2>` `<h3>` | 页面标题和分节标题 |
| `<p>` | 段落文字 |
| `<img>` | 插入图片 |
| `<figure>` `<figcaption>` | 图片及其说明文字 |
| `<ul>` `<li>` | 无序列表（演员列表） |
| `<video>` | 播放本地视频文件 |
| `<a>` | 超链接 |
| `<hr>` | 水平分割线 |
| `<div>` | 布局容器 |
| `<style>` | 页面样式 |

## 遇到的困难及解决方法

1. **图片无法并排显示**：最初海报和剧照是上下排列，页面显得很空。通过查阅资料学习 `flex` 布局，将图片放入同一个 `<div class="img-row">` 容器中，并设置 `display: flex` 和 `flex-wrap: wrap` 实现图片横向并排、自动换行。

2. **本地图片路径问题**：一开始使用绝对路径和网络图片链接，后来按照作业要求统一改为 `./images/` 相对路径，确保把整个文件夹提交后图片也能正常显示。

3. **预告片无法播放**：最初想用 `<iframe>` 嵌入爱奇艺预告片，但爱奇艺有防盗链限制，无法嵌入。最后改用 `<video>` 标签播放本地下载的 `trailer.mp4` 文件，并保留在线观看链接作为补充。

## 运行方式

使用 VS Code 的 Live Server 插件打开 `index.html`，或直接用浏览器打开该文件即可查看页面效果。
